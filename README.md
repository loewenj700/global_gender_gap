# Global Gender Gap — Labor Force Participation

Companion notebooks and datasets for John Loewen's [Medium articles](https://medium.com/@johnloewen) on global gender gaps in labor force participation.

## Notebooks

| Notebook | Article |
|---|---|
| [dumbbell_gender_gap.ipynb](dumbbell_gender_gap.ipynb) | The Dumbbell Chart Principle: How Cairo's Comparison Rule Exposes Global Gender Gaps |

## Data

- `data/female_lfp.csv` — World Bank [SL.TLF.CACT.FE.ZS](https://data.worldbank.org/indicator/SL.TLF.CACT.FE.ZS): female labor force participation rate (%), all countries + aggregates, 1990–2025
- `data/male_lfp.csv` — World Bank [SL.TLF.CACT.MA.ZS](https://data.worldbank.org/indicator/SL.TLF.CACT.MA.ZS): male labor force participation rate (%), all countries + aggregates, 1990–2025
